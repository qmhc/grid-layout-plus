# Changesets

Changesets record user-facing changes before they are released.

Run `pnpm changeset`, select `grid-layout-plus`, choose the SemVer impact, and write a concise
English summary. Commit the generated Markdown file with the pull request.

Documentation-only, test-only, and internal maintenance changes do not need a changeset.
See [`RELEASING.md`](../RELEASING.md) for the complete release flow.
